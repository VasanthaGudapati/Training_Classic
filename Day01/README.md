# 🧩 Day 01: Variables, Flow Control & Functions

## 📚 Concepts Learned Today
- **Variables & Types**: Integer conversion, basic data types (`int`, `str`).
- **Flow Control**: `while` loops, `if / elif / else` conditional branches, input validation.
- **Functions**: Scope, return values, helper modularity (`load_high_score`, `save_high_score`, `play_game`).
- **File I/O**: Reading and writing local text files (`high_score.txt`).

## 🚀 How to Run
From the repository root, run:
```bash
python Day01/main.py
```
