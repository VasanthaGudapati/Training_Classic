# 🔤 Day 03: Strings & String Manipulation Algorithms

## 📚 Concepts Learned Today
- **String Immutability & Memory**: Memory allocation of character arrays/strings and why strings in Python are immutable.
- **Two-Pointer Pattern**: Efficient $O(N)$ string reversal and palindrome detection using start/end pointer manipulation.
- **Substring Search**: Naive pattern matching ($O(N \times M)$) built without using Python's built-in `in` or `find()`.
- **Frequency Hash Maps**: Validating Anagrams in $O(N)$ time using character frequency counts.
- **Sliding Window Technique**: Finding the length of the longest substring without repeating characters in $O(N)$ time.

## 🚀 How to Run
From the repository root, run:

python Days/Day03/main.py
