# 🧩 Day 01: Variables, Flow Control & Functions

## 📚 Concepts Learned Today
- **Variables & Types**: Data types (`int`, `str`), casting, and variable scope.
- **Flow Control**: `while` loops, `if / elif / else` conditional branches, and input validation.
- **Functions**: Scope, return values, helper modularity (`load_high_score`, `save_high_score`, `play_game`).
- **File I/O**: Safe reading and writing to disk (`high_score.txt`).

## 🚀 How to Run
From the repository root, run:
```bash
python Days/Day01/main.py
```
