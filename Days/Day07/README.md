# 🏦 Day 07: Object-Oriented Programming (OOP) & Banking System

## 📚 Concepts Learned Today
- **Pillars of OOP**:
  - **Encapsulation**: Protecting internal state using private/protected instance variables (`_balance`, `_account_number`) and controlling access via getters and methods.
  - **Inheritance**: Extending base functionality from `BankAccount` into specialized subclasses (`SavingsAccount`, `CheckingAccount`).
  - **Polymorphism**: Overriding behaviors like `withdraw()` across different account types to enforce distinct rules (e.g., overdraft limits in checking accounts).
  - **Abstraction**: Utilizing abstract interface patterns for transactions and account operations.
- **Transaction History**: Logging financial transactions with timestamps and type tracking.

## 🚀 How to Run
From the repository root, run:
```bash
python Days/Day07/main.py
```
