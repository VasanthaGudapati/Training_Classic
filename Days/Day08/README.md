# 🥞 Day 08: Stacks & Queues (Linear Abstract Data Types)

## 📚 Concepts Learned Today
- **Stack Data Structure (LIFO - Last-In, First-Out)**:
  - Operations: `push()`, `pop()`, `peek()`, `is_empty()`, `size()`.
  - Applications: Function call stacks, expression evaluation, undo/redo mechanisms, and balanced parenthesis matching.
- **Queue Data Structure (FIFO - First-In, First-Out)**:
  - Operations: `enqueue()`, `dequeue()`, `peek()`, `is_empty()`, `size()`.
  - Applications: Task scheduling, print job queues, and Breadth-First Search (BFS).
- **Bracket Validation Algorithm**: $O(N)$ stack-based validation of nested mathematical expressions containing `()`, `[]`, `{}`.
