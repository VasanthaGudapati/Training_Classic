# 📊 Day 02: Dynamic Arrays & Array Resizing

## 📚 Concepts Learned Today
- **Contiguous Memory**: Static vs. dynamic arrays, continuous memory allocation, and array indexing.
- **Time Complexity**: $O(1)$ random access by index vs. $O(N)$ insertion/deletion due to element shifting.
- **Amortized $O(1)$ Complexity**: Geometric expansion (capacity doubling) strategy to achieve amortized constant-time append operations.
- **Custom Implementation**: Building a `DynamicArray` class from scratch with low-level fixed-capacity buffer allocation, index validation, capacity doubling, and element shifting.

## 🚀 How to Run
From the repository root, run:
```bash
python Days/Day02/main.py
```
