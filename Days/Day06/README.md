# 📶 Day 06: Basic Search & Sorting Algorithms

## 📚 Concepts Learned Today
- **Searching Algorithms**: Linear Search ($O(N)$) vs. Binary Search ($O(\log N)$) on ordered datasets.
- **Comparison-Based Sorting ($O(N^2)$)**:
  - **Bubble Sort**: Neighboring element swaps moving largest elements to the end.
  - **Selection Sort**: Repeatedly finding minimum elements from unsorted subarrays.
  - **Insertion Sort**: Building a sorted array slice item by item.
- **Divide and Conquer ($O(N \log N)$)**:
  - **Merge Sort**: Recursively splitting array into halves and merging sorted halves in $O(N)$ time.
- **Precondition Verification**: Enforcing array sorting before executing logarithmic binary searches.
- **Benchmarking**: Speed performance comparisons across various array sizes.
