# 🔁 Day 04: Recursion & Time Complexity Analysis

## 📚 Concepts Learned Today
- **Recursion Fundamentals**: Base case, recursive case, and execution call stack.
- **Recursion Stack Dynamics**: Visualizing call stack frames, stack overflow risk, and depth tracking.
- **Time Complexity ($O(2^N)$ vs $O(N)$)**: Demonstrating exponential growth of naive recursive Fibonacci vs linear dynamic programming / memoization.
- **Memoization (Top-Down Dynamic Programming)**: Caching recursive subproblem outputs to eliminate redundant operations.
- **Classic Recursive Algorithms**: Tower of Hanoi move visualizer and recursive factorials.

## 🚀 How to Run
From the repository root, run:
```bash
python Days/Day04/main.py
```
